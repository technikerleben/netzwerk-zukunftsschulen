# Netzwerkjahr 2026/2027

## Arbeitsschwerpunkt
**Kompetenzraster als Scharnier zwischen selbstreguliertem Lernen und Leistungsbewertung**

Untertitel:

**KI-gestützte Entwicklung von Kompetenzrastern, Lernaufgaben und Bewertungslogiken**

## Anschluss an die bisherige Netzwerkarbeit

1. **Selbstreguliertes Lernen** – didaktischer Überbau
2. **KI im schulischen Kontext** – digitale Werkzeuge als Unterstützung professioneller Arbeit
3. **Leistungsbewertung** – Transparenz, Fairness und neue Prüfungsformate
4. **2026/2027: Kompetenzraster** – Verbindung der drei bisherigen Entwicklungsstränge

## Grundidee

Im Netzwerkjahr 2026/2027 entwickeln und erproben Entwicklerteams keine isolierten Tabellen, sondern kleine **Lernarrangements mit Kompetenzrastern**.

Ein Entwicklungsprojekt verbindet möglichst:

- eine fachliche oder überfachliche Kompetenz,
- ein überschaubares Kompetenzraster,
- eine passende Lernaufgabe oder Aufgabenfolge,
- einen Bezug zum selbstregulierten Lernen,
- eine nachvollziehbare Bewertungslogik,
- einen dokumentierten Einsatz digitaler Tools oder KI durch Lehrkräfte bei der Planung.
